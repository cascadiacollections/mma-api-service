Event data policy

Effective September 20, 2026

Current source and scope

The service currently normalizes a limited set of factual event information from ESPN's publicly reachable UFC scoreboard feed: event names and dates, bout identifiers, fighter names and records, weight classes, statuses, and winner indicators. It does not copy articles, commentary, video, photography, logos, betting lines, or broadcast content.

Responsible access

Requests are made by the server with an identifying user agent. Concurrent requests are coalesced, scheduled and live cards use bounded refresh periods, and completed cards are cached for up to 24 hours. The browser never contacts the event provider directly.

No affiliation or data license claim

Public technical availability does not imply endorsement or a commercial data license. ESPN, Disney, UFC, Zuffa, event names, fighter names, and related marks belong to their respective owners. The service will not bypass authentication, CAPTCHAs, rate limits, paywalls, or other access controls.

Provider changes and rights concerns

The provider adapter is isolated so it can be replaced with a licensed source before commercial operation or if access terms change. Rights holders may raise attribution, access, or removal concerns through the project repository or the repository owner's GitHub profile. Confidential notices should not be posted in public issues.
