Privacy notice

Effective September 20, 2026

No accounts or pick database

MMA Pick'em does not create user accounts, set application cookies, use advertising trackers, or store submitted picks in a server-side database. Shared picks are encoded in the URL fragment after the #. Web browsers do not send that fragment with the page request.

Theme preference

If you choose a visual theme, the browser stores that preference locally under mma-pickem-theme. It is not transmitted to the server and can be removed by clearing site storage.

Operational logs

The hosting platform, network provider, or reverse proxy may temporarily log ordinary request information such as IP address, user agent, timestamp, requested path, response status, and latency. URL fragments containing picks are not included. Retention and access are controlled by the deployment operator and hosting provider.

Event data and cache

The server requests event information from a third-party provider and may cache that event information in memory or Redis. The cache contains event data, not user identities or shared picks.

External links

Links to GitHub or other sites are governed by those services' privacy practices. This notice does not cover independently operated deployments of the open-source project.

Advertising

Advertising is disabled unless a deployment operator configures a Google AdSense publisher account. If enabled, Google and its partners may use cookies or similar technologies subject to their policies and applicable consent requirements. Deployments serving regions that require consent must configure a Google-certified consent management platform before enabling personalized advertising.

Children

The service is not directed to children under 13 and does not knowingly collect personal information from them.

Questions

Privacy questions may be directed to the repository owner through the project repository. Do not include private information in a public issue.
