# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a
vulnerability** feature for this repository. Do not open a public issue with
exploit details or sensitive information.

Include the affected endpoint or component, reproduction steps, potential
impact, and any suggested mitigation. Reports will be acknowledged as soon as
practical.

## Supported versions

The latest deployment from the `main` branch is supported. Older revisions and
third-party deployments are not maintained by this project.
